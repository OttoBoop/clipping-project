# V1 Delivery Scope

_Created 2026-05-19 by Atlas/Codex._

This is the bounded delivery scope for the first sellable clipping package. It
is intentionally conservative so the product funds development instead of
becoming unlimited manual work.

## Base Package

```text
private scoped dashboard
operator-run updates
agreed targets/terms
grouped stories and article links
scoped raw text when available
one lightweight manual summary/export when agreed
```

## Recommended First Offer

For the first paid client, propose a pilot rather than an unlimited retainer:

```text
duration: 30 days
targets/terms: up to 5 monitored people/topics
update frequency: 2 operator-run updates per week
delivery: private dashboard + one weekly manual summary
support: password/access help during business hours
review: end-of-pilot decision on frequency, targets, and add-ons
```

Delivery format decision:

```text
V1_DELIVERY_FORMAT_DECISION.md
source of truth: private scoped dashboard
included artifact: one lightweight weekly written summary
channels: plain text, email, WhatsApp, or small manual screenshot/export
not included: custom branded PDF, automated bot, daily AI brief, realtime alerts
```

Why this shape:

- weekly-only may feel too slow for politics;
- daily updates may create too much operator burden before pricing is proven;
- two updates per week is enough to prove usefulness without promising
  realtime coverage;
- one weekly summary keeps human value visible while limiting manual writing.

## Included

- one viewer profile/password;
- one scoped target/profile config;
- target terms agreed before the pilot starts;
- operator-run update jobs on the agreed schedule;
- dashboard access through the current FastAPI/Render app;
- basic QA after target/profile changes;
- weekly short written summary or screenshot/export prepared by Otavio.

## Not Included In Base

- realtime alerts;
- daily summaries;
- unlimited targets;
- self-service target creation;
- custom sources researched on demand;
- custom site/repo/branding;
- social listening, TV, radio, print, or WhatsApp monitoring;
- finished Rio economic indicator;
- crisis-room support.

## Add-Ons To Price Separately Later

- extra weekly update runs;
- extra targets/topics;
- WhatsApp/PDF summary;
- human classification/sentiment pass;
- competitor/agenda topic track;
- Rio economic methodology or topic dashboard;
- custom source onboarding.

## Operator Metering

During the pilot, log:

```text
minutes per update run
minutes per QA/profile check
minutes per weekly summary
number of targets
number of collected stories/articles
AI/tool calls used
support issues
false positives or missed stories
```

Do not set permanent pricing until these numbers are known.

## Renewal Decision

At the end of the pilot, decide:

- keep same frequency;
- increase frequency as paid add-on;
- reduce/no renewal if signal is weak;
- add/remove targets;
- add manual summary or classification tier;
- create a dedicated prospect/client password rotation schedule.
