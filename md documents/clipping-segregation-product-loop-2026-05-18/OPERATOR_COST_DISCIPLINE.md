# Operator Cost Discipline - Segmented Clipping Product

_Created 2026-05-19 by Atlas/Codex._

This product is supposed to help Otavio pay for AI tools, hosting, and
maintenance. It must not become unlimited manual research for every client.

## Rule

Sell a bounded monitoring service first, not bespoke intelligence work.

The V1 product should be:

```text
configured targets -> operator-run clipping -> private scoped dashboard ->
optional manual summary/export
```

## Keep Included In V1

- one private profile/password per client;
- agreed target list or topic list;
- periodic operator-run updates;
- grouped stories and article links;
- scoped raw text where available;
- basic human review when needed;
- occasional manual export/screenshot/report.

## Keep Out Of The Base Price

- unlimited new targets;
- unlimited custom source research;
- real-time alerts;
- custom frontend or custom repo;
- client self-service target creation;
- daily AI-written narrative reports;
- social listening, TV, radio, or print monitoring unless separately priced;
- Rio economic indicator methodology work.

## Meter Before Promising

Track these before setting a price:

- minutes per update run;
- minutes per client review;
- number of targets monitored;
- number of sources/collectors needed;
- AI calls or paid-tool usage per update;
- manual export/report time;
- support time for password/access issues.

## Packaging Guardrail

For a first paid client, define in writing:

- target/profile name;
- update frequency;
- included targets/terms;
- included delivery format;
- what counts as an add-on;
- what is explicitly not included.

## Loop Check

Before adding a feature because a possible buyer asks for it, record:

```text
Will this be reused by multiple clients?
Does it reduce operator time?
Does it increase AI/tooling cost?
Can it be priced separately?
Does it risk data leakage or profile pollution?
```

If the answer is mostly "no", keep it as a manual add-on or reject it for V1.
